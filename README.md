# 🍕 Pizzaria Planet

Site de uma pizzaria fictícia, desenvolvido para praticar HTML e CSS na criação de uma página institucional com cardápio e informações de contato.

🔗 **Online:** [brenoryan-dev.github.io/PizzariaPlanet](https://brenoryan-dev.github.io/PizzariaPlanet/)

## Sobre o projeto

Página única (single page) com navegação por âncoras entre as seções. Simula o site de um pequeno negócio local, apresentando a pizzaria, seu cardápio, quem somos e como entrar em contato para fazer pedidos.

> Os dados de contato e o endereço exibidos no site são de exemplo e fazem parte do projeto de estudo.

## Seções do site

- **Home:** boas-vindas e botão "Ver cardápio"
- **Cardápio:** lista de pizzas com foto, nome e ingredientes
- **Sobre Nós:** apresentação da pizzaria e da proposta de cultura italiana
- **Contato:** endereço, telefone, e-mail e horário de funcionamento

## Funcionalidades

- Menu de navegação que leva direto a cada seção
- Cardápio em formato de cards com imagem e descrição
- Informações de contato e horário de atendimento
- Meta tag de viewport configurada para telas de diferentes tamanhos

## Tecnologias utilizadas

- HTML5
- CSS3
- GitHub Pages (hospedagem)

## Como rodar localmente

1. Clone o repositório:

```bash
git clone https://github.com/brenoryan-dev/PizzariaPlanet.git
```

2. Entre na pasta:

```bash
cd PizzariaPlanet
```

3. Abra o `index.html` no navegador, ou use a extensão **Live Server** do VS Code.
